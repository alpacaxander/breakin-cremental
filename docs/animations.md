# Animations

One row per animation, matched to the full asset list. All are horizontal strips `assets/pixel/png/anim_<name>.png`, native 1x pixels, held frames repeated. Rules in `docs/art-style.md` (Animation section). Generated by `assets/pixel/gen.mjs`. fps: 12 for hits and effects, 8 for idle loops.

Hue sets: mag (currency 1), ora (currency 2), vio (currency 3), mint (placeables), sky (conditional), yellow (payout).
