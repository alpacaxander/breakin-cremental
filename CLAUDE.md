# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

BreakIn cremental: "Peglin, but breakout", a run-based roguelike in Godot 4.7 (GDScript). Bricks are pegs, balls are the deck, enemies act on the board. A run is a branching map of fights, elites, treasure, events and a shop, ending at a boss; the bag of balls, the relics, gold and HP carry from node to node, and meta-unlocks carry across runs. The incremental loop (currency, upgrade web, placement, timed rounds) was cut on 2026-11-09; its sprites and cues are still generated as candidates. Design, status and risks: `docs/design.md`. Every number, name and per-moment strip and cue: `docs/content.md` (the contract; it wins over design.md). Bricks, boards, the fight pipeline, encounters, organs, enemies and hazards: `docs/encounter-mechanics.md` (decided rules on top, the older rows under "Not verified").

## Commands

Godot and xvfb-run are not on PATH; they come from the Nix dev shell (`nix develop`, or prefix commands with `nix develop -c`).

```sh
godot                                  # open the editor on this project
godot --headless -s tests/test.gd      # rules self-check (game.gd, tuning.gd tables, strips, cues); prints "ok" or FAIL lines, exits 1 on failure
godot --headless tests/smoke.tscn      # scripted fights poking every mechanic, then a walk through the run screens; any script error prints. A scene, not -s, so the Game autoload exists
nix develop -c xvfb-run -s "-screen 0 3840x2160x24" godot --display-driver x11 --rendering-driver opengl3 tests/shots.tscn  # every screen at eight window sizes to user://shots/, to eyeball the layout
node assets/pixel/gen.mjs              # regenerate every sprite and animation strip in assets/pixel/png/ (needs ImageMagick `magick`)
node assets/audio/gen.mjs              # regenerate every sound cue in assets/audio/wav/ and the review page assets/audio/demo.html
```

There is no test framework and no lint step. `tests/test.gd` is a plain `SceneTree` script using a `check(ok, msg)` helper; add a line there when a rule changes. The smoke test saves the real `user://run.json` and `settings.json` and restores them afterward.

## Architecture

Ten scripts in `src/`, no scenes except `main.tscn`. Everything is built in code.

- **`tuning.gd`** is the single home for every number and table. Fight: the paddle and ball constants, `BOARDS` (generator settings per board class: fight, elite, boss), `BRICKS` and `ICON_KINDS`, `PIECES` (paddle, mini paddle, wall, organ cell), `BALLS` (dmg per rank, trait values, optional `effects` rows with per-rank numbers), `ORGANS` (an enemy on the board: hp, `cd`, intent cycle, tint), `ENCOUNTERS` (one fight: role, tier, organs, drawn board with organ digits, `cd_start`, `win`, band portrait, optional `effects` rows, else `KEEP_DEFAULT`), `LAYERS`, `ENEMIES` (legacy rows, each played as a one-organ encounter through `encounter()`'s bridge; `organ(id)` and `encounters()` read both tables), `HAZARDS`, `MOUTH`, `RELICS` (rarity, a `hook` from `RELIC_HOOKS` or, for a placement relic like `tenth_bomb`, `effects` rows). Run: `RUN` (hp, beats, speed ramp), `GOLD`, `REWARDS`, `SHOP`, `RARITY`, `RELIC_RARITY`, `BAG_START`, `MAP` (layers of weighted slots and edges), `EVENTS`, `UNLOCKS` (meta flag -> ids it unlocks; a row's `locked` names a flag). `spec(kind)` finds a kind's row, `hue(kind)` its colour group. Changing balance means editing this file only; `test.gd` enforces the cross-references (intents name hazards, locked names a flag, every face and strip exists).
- **`game.gd`** (autoload `Game`) holds settings (`settings.json`, with meta flags and run/win counts under `meta`), the run state (`run`: hp, gold, bag, relics, map and path, `pending` node, stats) with its autosave `run.json`, and the pure rules: `gen_map`, `enter_node`, reward/shop/enemy/relic rolls (seeded per node by `rng(site)`), event choices, gold and HP, the bag invariant and bag uids (`tag_bag`), a fight's ordered effect rows (`fight_effects`), and `generate(cls, seed, board)` for boards. No scene dependencies, so `test.gd` instantiates it headless.
- **`main.gd`** drives the run: menu (PLAY / CONTINUE, plus the CATALOG of balls and encounters met, `meta.seen`) -> map -> the node's screen -> map, until the boss falls or HP hits 0, then the end screen. A fight is `arena.gd`; the map, shop, event, treasure, reward overlay and end screens are built here from `Ui` helpers. It autosaves on every screen change, never mid-fight, so CONTINUE resumes at the node entered. The run screens and the fight are the play group: Esc opens the one pause dialog, and MENU drops the screen (a fight is abandoned, the last autosave stands).
- **`arena.gd`** is one encounter: the band portrait above the top wall, the board with its organs (inner `Organ` nodes, each with HP, countdown, intents and poison, its cells `Box`es of kind `organ`), the bag launched phase by phase, and the damage pipeline (a ball stores damage per brick, cashes it in on touching an organ cell, which consumes the ball (`_organ_hit`, `_land`; the paddle lands nothing), loses it on a drop; a phase ends when every ball has dropped or been consumed; the fight is won when the encounter's `win` organs are dead). Seconds with a ball in flight count down each organ's intent (`_count_down`, `_tick`); at 0 its hazard spawns from that organ (`_act`, `_hazard`, inner `Hazard` nodes). Ball traits live on the inner `Ball` class (`CharacterBody2D`) and in `_break` / `_paddle_hit`; relics fire through `_relics(hook)`, stat relics are `Game.has` reads where their number applies. Brick placement is effect rows from `Game.fight_effects` (encounter, then relics, then bag balls): `start` rows once (`_start` on the layout before the spawn, `_apply` for layers), `keep` rows in `_keep`. Brick-kind behaviour is in `_hit`, `_damage` and `_effect`, keyed by `kind`. Arena-local px, origin top-left, `field` = `Tuning.ARENA`; `_fit` scales the node into the cabinet's 4:3 field (`Ui.Root.content`). Mouse reads go through `get_local_mouse_position`. Emits `done(win)` after the end beat.
  - **`hud.gd`** is the fight's two run columns (YOU: HP, gold, phase, damage, balls in play, relics; BAG: the queue and DISCARD), read from the arena every frame through an untyped `arena` var.
- **`brick.gd`** (`Box`) is every physical piece: board bricks, paddles, walls. It builds the collider and look from the kind's `tuning.gd` row (`face`, `idle`, `halo`, `offset`). `set_kind` is the one way a live piece changes kind (the arena wraps it in `_convert` to keep its breakable count); `source` and `keep` tag who made a brick; `layer` is the coat on top (overlay sprite, `add_layer` / `drop_layer`, survives `set_kind`).
- **`fx.gd`** plays horizontal animation strips from `assets/pixel/png/anim_<name>.png` as `AnimatedSprite2D` at 2x, slicing by a caller-supplied frame width. One `SpriteFrames` is cached per strip, so a strip must always be played at the same fps.
- **`sfx.gd`** plays one cue from `assets/audio/wav/<name>.wav`: `play(name, pitch, delay)` one-shots under the scene root (they survive scene swaps and pauses), `loop(parent, name)` as a child that stops with its owner. Pitch ladders reuse one sample (`st(n)` = n semitones; `Tuning.ladder` picks a step by count). `Ui.button` plays `ui_click` unless given another cue or `""`; `test.gd` checks every cue name the scripts play has a wav.
- **`editor.gd`** is the encounter editor, a dev tool off the run (the menu's EDITOR, debug builds only): a board of half-brick cells (a brick is 2x1) painted, dragged, moved and copy-pasted with snapping, layer coats painted onto pieces (`Tuning.LAYER_KEYS`), the refresh keep count (KEEP, saved as the row's `effects` only when it differs from `KEEP_DEFAULT`), the encounter's organs and role, and a test loadout (bag, relics, HP, gold). SAVE writes `encounters/<name>.json`, an `ENCOUNTERS` row whose `board.half` rows (and `board.layers` when anything is coated) `Game.generate` reads as is, painted bricks and coats standing as design start placements, plus the loadout; PLAY runs it in `arena.gd` (its `enc` handed in) on a throwaway `Game.run`, never saved. A design reaches the game by copying its row into `ENCOUNTERS`.
- **`ui.gd`** is the cabinet: every screen is a 640x360 sprite-space layout scaled 2x (`Ui.Root`), centred in a canvas that grows with the window. `main.gd` `_scale` sets the window's `content_scale_factor` to the factor at which 1280x720 just fits (Godot's own stretch is off: it letterboxes). Left to right: padding, column, 4:3 field (480x360 sprite px), column, padding. Below 1280x720 the columns keep their 2x (`sheet`, `left`, `right` are `top_level`) and `Ui.Root.content` shrinks the field to the largest 4:3 left between them; `fit()` lays them out on every resize. Static helpers (`chassis`, `run_columns`, `bag_rows`, `card`, `hp_bar`, `hotspot`, `label`, `button`, `icon`, `pips`, `dialog`, `overlay`, `settings`) place things in sprite px; `theme.tres` supplies the 3x5 bitmap font and the nine-patch button, toggle and slider styles.

### Adding a brick kind

A kind is a string that several tables and `match` blocks agree on. Touch, in order:

1. `tuning.gd`: a row in `BRICKS` with a `hue` (mag basic, ora bomb, mint refresh, red hazard), and a weight or count for it in the `BOARDS` classes (or an encounter's `board`); add it to `ICON_KINDS` if its face is a pulse strip.
2. `game.gd` `generate` if it has placement rules; `arena.gd` for the arm it needs: `_hit` for a bounce reaction, `_damage` for a refusal or multi-hit face, `_effect` for an on-break effect. An area effect sets off neighbours through `_trigger` (never `_break` directly) and finds them with `_live` or `_near`. Hit, break and spawn strips come from `Tuning.hue(kind)`.
3. Art and sound: `assets/pixel/gen.mjs` (or its `parts/`), `docs/animations.md`, `assets/audio/gen.mjs`, and the strip list in `test.gd`.

## Art pipeline

Sprites are pixel art on a 640x360 canvas shown at 2x (nearest filtering, set in `project.godot`). Game-space sizes in `tuning.gd` are 2x the sprite sizes (a 60x24 brick is a 30x12 sprite). All PNGs are generated by `assets/pixel/gen.mjs` and committed; do not hand-edit them. The Peglin-direction art lives in `assets/pixel/parts/*.mjs` (bricks, balls, enemies, boss, hazards, icons, fight effects, mock screens): each exports `emit(h)` and takes the helpers it needs from `gen.mjs` as one object, since `gen.mjs` exports nothing. The UI font is `assets/pixel/png/font_3x5.fnt` (BMFont descriptor, also generated) over `font_3x5.png`; Godot imports it as a `FontFile` and the UI asks for sizes 5, 10, 15 and 20. Mock screens, logo cards and `look.png` land in `assets/pixel/preview/` (`.gdignore`, so Godot never imports them); `preview/ui.html` shows them. The strip name, frame width and frame count every call site uses must match `docs/animations.md`, and `test.gd` checks that each strip the arena plays slices into the documented frame count. `docs/art-style.md` and `docs/palette.md` describe the lamp look and colours; when the docs and `gen.mjs` disagree, the code wins and the doc gets fixed.

Sound cues are sfxr-style synthesis from `assets/audio/gen.mjs` (plain Node, no dependencies), committed as 44.1k mono WAVs; tune the recipe in its `CUES` table, never the wav. Noise is seeded per cue name, so a regen rewrites only the cues whose recipe changed. The run's five new cues come from `assets/audio/parts/demo.mjs`, a `CUES` fragment spread into that table; its header lists which existing cue and pitch every other moment reuses. The four loop cues carry `edit/loop_mode=1` in their `.import` sidecars; a new loop needs that flag too.

`assets/vector/` is an earlier SVG attempt, excluded from Godot import by `.gdignore` and not used by the game.

## Conventions

- Ponytail style: the smallest working change, and deliberate shortcuts are marked with a `# ponytail:` comment naming the ceiling and the upgrade path. Keep that habit.
- Each script opens with a `##` doc comment saying what it owns; keep those accurate when responsibilities move.
- Capture freed-able nodes in lambdas by instance id (see the spawn tween in `arena.gd`), not by reference.
- Quit through `Sfx.quit()`, never `get_tree().quit()` directly: a cue still mixing at exit logs a leaked playback. The window close button already routes there (`main.gd`).
